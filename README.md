# 竹知了 · 云甩竹蝉

基于中国传统民间玩具「竹蝉（竹知了）」的 Web 互动游戏。单文件、零依赖、离线可玩。

> 竹鼓为鼓，松音为弦，蝉颤生振，振腔共鸣。

## 玩法

| 模式 | 操作 |
| --- | --- |
| 手动画圈 | 按住屏幕（或鼠标）画圈，像甩真竹蝉一样；转得越快，叫得越响。触屏时锚点自动抬到指尖上方，避免手指挡住小蝉。 |
| 自动甩 | 点「自动甩」按钮或按 **空格键**，程序自动替你画圈。 |
| 甩手机（移动端） | 点「甩手机」并握住手机画圈，用动作传感器（陀螺仪/重力方向在机身坐标中的转动）驱动甩杆。 |

- 支持顺时针与逆时针旋转；转速低于约 1.1 圈/秒或绳子未绷紧时不发声；松手后竹蝉随惯性自然减速，在重力作用下缓缓回到绳子最低处。
- 每完整旋转一圈，「功德」+1（保存在设备本地 localStorage，可持续累计）；另有「本局哇声」「本局圈数」统计。
- 快捷键：`空格` 自动甩 · `S` 手绘/3D 形象 · `L` 排行榜 · `A` 成就 · `D` 昼夜主题 · `M` 静音 · `Esc` 关闭面板

## 运行方式

1. **直接打开**：双击 `index.html`（推荐 Chrome / Edge / Safari / Firefox）。
2. **局域网试玩（HTTP）**：在项目目录启动静态服务，手机连同一 Wi-Fi 访问：

   ```bash
   python -m http.server 8123
   # 手机浏览器访问 http://<电脑IP>:8123（电脑 IP 用 ipconfig 查看 WLAN 的 IPv4 地址）
   ```

   HTTP 方式下画圈甩、自动甩、音效、功德统计全部正常，**仅「甩手机」传感器不可用**（见下节）。

## 动作传感器（甩手机模式）支持

浏览器规定：传感器事件只在 **HTTPS 或 file://** 环境下可用。按手机系统选择：

**Android（最简单）**
1. 把 `index.html` 通过微信文件传输助手 / QQ / 网盘 / 数据线传到手机；
2. 在文件管理器中点开，选择用 **Chrome / Edge 浏览器打开**（即 file:// 协议）；
3. 打开后点「📱 甩手机」→ 允许权限（部分机型会弹授权框）→ 握住手机画圈即可。

**iPhone（需要 HTTPS）**
1. 电脑上生成自签名证书并启动 HTTPS 服务器（证书与私钥不入库，首次使用先运行 `make_cert.py` 生成）：

   ```bash
   # 若更换了网络/电脑 IP，可重新生成证书（把 IP 换成当前 ipconfig 查到的）：
   python make_cert.py 192.168.x.x
   # 启动 HTTPS 静态服务器（首次会通过 npx 下载 http-server）：
   npx http-server -S -C cert.pem -K key.pem -p 8123 -a 0.0.0.0
   ```

2. 手机 Safari 访问 `https://<电脑IP>:8123`，出现证书警告时点「显示详细信息 → 访问此网站」；
3. 点「📱 甩手机」→ 首次会弹「请求动作与方向访问」→ **允许**；
4. 若之前误点过「不允许」，去 设置 > Safari > 运动与方向访问（或 设置 > 隐私 > 运动与健身）开启后刷新重试。

**常见问题排查**
- 提示「当前浏览器不支持动作传感器」→ 多半是在微信/QQ 或 App 内置浏览器、或电脑浏览器里打开的；请改用手机自带 Chrome/Edge/Safari。
- 提示「未收到传感器数据」→ 检查是否已授权；确认手机有陀螺仪（几乎所有现代手机都有）；实在不行可用「自动甩」代替。
- 设备在桌面端浏览器没有陀螺仪事件属正常现象，请用手机访问。

## 技术要点

- **零依赖单文件**：所有代码、样式、资源（含音效）整合在一个 HTML 中，无需构建、无需联网。
- **物理模拟**：竹筒为绳系质点，含重力、只拉不推的弹性绳约束、空气阻力（线性 + 平方），以 1/240s 定步长积分。
- **音效**：1.72 秒采样（恰好 4 个「哇」周期，对应约 2.33 圈/秒的录音甩速），尾部 50ms 等功率交叉淡化做成无缝循环；回放速率随转速实时变化并叠加每圈相位的音高微摆；采样构建失败时自动回退到纯合成音效链路（锯齿波 55~195Hz + tanh 软削波 + 24~45Hz 低频调幅 + 带通摩擦噪声 + 1050/2150/3350Hz 三并联共振峰 + 随转动相位扫频）。
- **渲染**：Canvas 2D 伪 3D 竹蝉（翅膀纹理、旋转模糊、竹节高光），深蓝夜空 + 竹林剪影 + 月夜氛围，可切换 2D 手绘小蝉形象与白天/夜间主题。
- **数据**：功德、圈数、哇声、成就、排行榜、昵称均存于 localStorage；在线人数、全球访客/哇声为本地演示数据（本文件无服务器，离线运行）。
